# 云听 AI 智慧心理教室

当前仓库仅保留最新版静态产品原型，包含统一登录、老师端、学生端、课程库、课堂管理和课堂记录。

## 本地运行

```bash
python3 -m http.server 8900
```

浏览器打开：`http://127.0.0.1:8900/`

## 当前实现边界

- 老师统一控制与学生自主探索两种课堂流程已在同源浏览器演示链路中实现。
- 当前课堂在线、重连、未进入及逐学生进度属于前端演示状态。
- 正式跨设备实时课堂仍需接入服务端鉴权、逐学生状态、心跳、WebSocket/SSE、场次隔离和持久化记录。
- 心理指数与学生洞察为演示数据；不能替代专业量表、人工复核或诊断。

## 主要入口

- `index.html`：统一登录
- `teacher.html`：老师工作台
- `student.html`：学生首页
- `teacher-course.html`：课堂管理
- `course.html`：学生课堂
- `teacher-record.html`：课堂记录详情
