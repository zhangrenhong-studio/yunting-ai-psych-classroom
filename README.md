# 云听 AI 智慧心理教室

面向学校心理健康活动课的 AI 互动课程平台。当前仓库保存可运行的前端产品原型与产品需求文档，作为后续迭代基线。

## 当前能力

- 学生端首页与成长空间
- 独立的小悦悦聊天、心理成长音频、每日记录、留言墙与课堂记录页面
- 六环节课堂体验：进入课堂、故事导入、和小悦悦聊聊、心理能量补给、成长训练场、收束与尾声
- 老师端开课准备、班级管理、课程管理、课堂控制、课堂记录、成长观察与私密关注
- 48 节年级课程规划、5 个通用专题，以及 2 节已制作课程内容包
- 老师统一控制与学生自主探索两种课堂推进方式

## 重要说明

当前版本是**静态前端功能原型**：

- 数据保存在浏览器 `localStorage`；
- 课堂同步通过同源 `BroadcastChannel` / 本地状态模拟；
- 尚未接入真实账号、后端数据库、跨设备实时课堂、AI 服务和学校权限系统；
- 不应将当前演示描述为已具备正式学校部署能力。

## 本地运行

```bash
python3 -m http.server 8765
```

打开：

- 学生端：`http://127.0.0.1:8765/`
- 老师端：`http://127.0.0.1:8765/teacher.html`
- 课程管理：`http://127.0.0.1:8765/teacher.html?view=courses`

## 目录

- `assets/`：样式、脚本、音频和图片资源
- `courses/`：课程库与已制作课程内容包
- `teacher*.html`：老师端工作流
- `student-space.html`、`daily-record.html`：学生成长空间
- `docs/`：产品与交付文档

## 产品边界

云听不是心理诊断工具、自动测评系统或自由陪聊应用。学生表达只可作为带上下文的课堂观察材料，由有权限的老师人工理解；产品不自动生成疾病标签、心理分数或风险等级。
