# 云听 AI 智慧心理教室 PRD

**文档版本：** V1.0  
**产品阶段：** 前端功能原型 / 真实产品化前基线  
**适用范围：** 当前 GitHub 版本及后续产品迭代

---

## 1. 产品概述

### 1.1 产品定义

云听是一套面向学校心理健康活动课的 AI 互动课程平台。老师选择班级和课程并发起课堂，学生在同一节课中依次经历故事、私密表达、声音陪伴、成长训练和收束；老师负责课堂节奏、观察与人工跟进。

产品的核心不是让学生自由聊天，也不是通过一次互动自动判断心理状态，而是把心理健康教育转化为可复用、可参与、可由老师掌控的课堂体验。

### 1.2 核心价值

**对学生**

- 从故事和具体情境进入，不必一开始直接讲自己的问题；
- 在不公开个人表达的前提下，用自己的语言说一点感受；
- 不只听道理，还能体验音频、方法和成长训练；
- 课后留下属于自己的记录，也可主动向老师表达支持需要。

**对老师**

- 使用结构化课程快速开展心理活动课；
- 统一控制课堂，或允许学生按自己的节奏探索；
- 查看班级参与情况、课堂记录和学生主动提交的关注内容；
- 以原话、课程上下文和人工观察为依据，不依赖自动心理结论。

**对学校**

- 将单次活动转为可持续的课程化心理健康教育；
- 支持不同年级、不同主题的课程内容复制；
- 为未来的权限、留痕、审计和人工处置流程建立产品基础。

### 1.3 产品边界

云听不是：

- 心理疾病诊断工具；
- 自动风险评分或自动预警系统；
- 传统问卷、做题或闯关系统；
- 学生随时打开的自由 AI 陪聊应用；
- 心理老师或学校人工处置机制的替代品。

任何学生表达都必须保留来源和上下文，由有权限的人员人工理解。系统不得仅依据表达长度、互动次数、停留时长、颜色选择或训练完成度生成心理标签。

## 2. 目标用户与场景

### 2.1 核心角色

1. **心理教师 / 授课教师**：选课、选班、开课、控制课堂、查看记录和处理学生主动求助。
2. **学生**：进入课堂、参与故事和互动、使用成长空间、回看自己的记录。
3. **学校管理员（后续）**：维护组织、账号、角色、课程授权、数据策略与审计。

### 2.2 核心使用场景

- 心理教师为一个或多个同年级班级安排心理活动课；
- 课堂中由老师统一推进，学生在各自设备完成当前环节；
- 学生自主探索模式下，学生按自己的节奏完成课程；
- 课后学生在成长空间中使用聊天、音频、每日记录和课堂记录；
- 老师查看课堂参与状态、学生主动提交的内容和需要人工跟进的事项。

## 3. 产品信息架构

### 3.1 学生端

**首页**

- 和小悦悦聊聊
- 心理成长方案
- 每日记录
- 留言墙
- 课堂记录

首页采用卡片结构，小悦悦使用已确认原图完整呈现，不裁切、不滤镜、不重新绘制。各入口进入独立页面，不增加左侧导航栏。

**学生成长空间**

- 小悦悦聊天：完整聊天页面，交互形态接近常用 AI 聊天产品；当前不接入 AI，不生成虚假 AI 回复。
- 心理成长方案：提供多段音频，支持选择、播放、暂停、拖动进度和重复聆听。
- 每日记录：按日期新建、查看和删除记录；月历显示有记录的日期。
- 留言墙：展示班级共同表达；与私密聊天、给老师的内容严格分流。
- 课堂记录：查看本人参与过的课程与可回看的个人内容。

**课堂体验**

1. 进入课堂
2. 故事导入
3. 和小悦悦聊聊
4. 心理能量补给
5. 成长训练场
6. 收束与尾声

心理能量补给只承载音频或音乐聆听。成长训练场中的应用可自由选择、重复体验；完成一个训练不锁定其他训练，也不自动结束整堂课。

### 3.2 老师端

**开课准备（一级入口）**

- 多选同年级班级；
- 选择课程；
- 选择“老师统一控制”或“学生自主探索”；
- 创建课堂后进入独立的二级课堂控制页。

**课堂控制（二级页面）**

- 展示所选班级全部学生；
- 逐人显示在线、重连、未进入；
- 显示当前环节与完成状态；
- 显示班级汇总；
- 支持开始、推进、暂停、恢复和结束课堂。

**班级管理**

- 班级列表保持简洁；
- 创建班级必须进入独立页面；
- 年级必选，并决定可安排课程；
- 班级名称可自定义；
- 创建时不手填学生人数或配对人数；
- 在班级详情中添加或批量导入学生。

**课程管理**

- 保持左侧老师工作台导航；
- 课程按年级直接展开为三列卡片；
- 支持年级筛选；
- 当前课程规划包含 48 节年级课程和 5 个通用专题；
- 已完成内容包可带入开课准备。

**课堂记录与学生观察**

- 课堂记录展示班级、课程、时间、应到/实到、完成状态和人工观察；
- 成长观察必须能追溯到课程、环节、原话或老师记录；
- 私密关注只接收学生明确提交给老师或明确希望获得成人支持的内容；
- 普通聊天、每日记录和留言墙不得自动进入私密关注。

## 4. 课程体系

### 4.1 课程结构

课程采用可复用的六环节骨架。每节课程替换以下内容：

- 主题和教学目标；
- 故事情境；
- 小悦悦对话脚本；
- 心理能量音频；
- 成长训练；
- 收束提示与留言出口。

### 4.2 当前课程库

- 初中：七、八、九年级；
- 高中：高一、高二、高三；
- 每个年级规划 8 节课，共 48 节；
- 通用专题 5 个；
- 当前已制作两个课程内容包，以 `courses/lesson-01.js`、`courses/lesson-02.js` 为准。

### 4.3 样板课

首课为七年级《走进初中，拥抱新起点》，服务新生适应场景。课程帮助学生从角色故事进入，表达对新环境、同伴融入或学习节奏的感受，体验一个可用的方法，并留下自己的收束内容。

---

## 5. 核心业务流程

### 5.1 老师开课

1. 老师进入开课准备；
2. 选择一个或多个同年级班级；
3. 系统仅展示该年级可用课程；
4. 老师选择课程和推进模式；
5. 创建课堂并进入课堂控制页；
6. 学生进入等待状态；
7. 老师开始课堂并推进各环节；
8. 课堂结束后生成课堂记录。

### 5.2 学生课堂

1. 学生进入当前课堂；
2. 在老师控制模式下，只能访问当前开放环节；
3. 在自主探索模式下，可按自己的节奏完成后续环节；
4. 私密表达、班级共同表达和给老师的内容分别保存；
5. 完成收束后进入课程完成状态。

### 5.3 人工关注

1. 学生主动选择“想让老师知道”或明确请求成人支持；
2. 内容进入有权限老师的私密关注队列；
3. 老师查看原话、课程和环节上下文；
4. 老师标记已查看、需要跟进或按学校流程转介；
5. 系统保存操作记录，不自动给出诊断结论。

---

## 6. 数据与权限要求

### 6.1 核心数据对象

- 学校、教师、学生、班级与成员关系；
- 课程、课程版本与课程内容包；
- 课堂场次、推进模式与课堂状态；
- 学生在线状态、当前环节和完成状态；
- 学生个人记录、班级共同表达和私密关注内容；
- 老师人工观察、跟进状态和操作日志。

### 6.2 可见性分流

| 内容 | 默认可见范围 | 是否进入老师关注 |
|---|---|---|
| 小悦悦普通聊天 | 学生本人 | 否 |
| 每日记录 | 学生本人 | 否 |
| 班级留言墙 | 审核后的班级共同层 | 否 |
| 课堂个人表达 | 学生本人；授权与权限范围内的老师 | 按规则 |
| 想让老师知道 | 指定老师/心理教师 | 是 |

### 6.3 正式版要求

- 身份认证与角色权限；
- 数据加密、传输安全和最小权限；
- 学校级数据隔离；
- 敏感内容访问审计；
- 明确的数据保留、导出和删除策略；
- 人工处置负责人、响应时限和升级流程。

---

## 7. 视觉与体验要求

- 整体采用明亮、克制的蓝绿色，不使用粉色作为主视觉；
- 保留足够留白和清晰层级，避免浅灰、半透明小字；
- 电脑端和平板端优先，手机端在核心流程稳定后适配；
- 学生端各功能进入独立页面，不复制老师端左侧导航；
- 同一角色始终使用已确认原图，不抠图、不加滤镜、不添加未经确认的装饰；
- 老师端课程页保持三列课程卡片和年级筛选；
- UI 修改不得擅自移除已有功能或只通过叠加样式制造“新版本”。

---

## 8. 当前实现状态

### 8.1 已实现的前端原型

- 学生首页及五个独立功能入口；
- 小悦悦聊天界面（未接 AI）；
- 多段心理成长音频播放器；
- 带月历的每日记录；
- 留言墙和课堂记录；
- 六环节课堂；
- 老师开课准备、班级管理、课程管理、课堂控制和课堂记录；
- 老师统一控制 / 学生自主探索两种模式；
- 本地演示数据和同浏览器状态同步。

### 8.2 当前技术限制

当前版本为静态前端：

- `localStorage` 保存数据；
- `BroadcastChannel` / 同源本地状态模拟课堂同步；
- 不支持真实跨设备多人课堂；
- 不支持真实登录、学校组织和权限；
- 不支持服务端持久化、审计和备份；
- AI 服务尚未接入。

因此，当前版本可用于产品评审、课程演示和交互验证，不可直接作为正式学校生产系统。

## 9. 产品化优先级

### P0：真实课堂闭环

1. 教师、学生账号与学校/班级关系；
2. 服务端数据库和数据迁移；
3. 跨设备实时课堂状态；
4. 全班学生在线、重连、未进入和环节完成状态；
5. 课程场次、课堂记录和人工观察持久化；
6. 私密关注队列、权限和操作审计；
7. 首课完整内容与真实课堂体验验证。

### P1：课程与成长空间

1. 课程内容配置与版本管理；
2. 第二节及后续课程复制验证；
3. 小悦悦受控对话服务；
4. 成长音频与训练内容管理；
5. 学生个人记录跨设备同步；
6. 老师课后观察与跟进流程。

### P2：学校规模化交付

1. 学校管理员与组织管理；
2. 课程授权和排课；
3. 数据保留、导出和删除策略；
4. 审计、告警与人工处置 SLA；
5. 多学校隔离、监控、备份与容灾。

---

## 10. P0 验收标准

- 老师可在真实账号下创建班级、添加学生并安排课程；
- 老师选择班级和课程后可创建唯一课堂场次；
- 不同设备上的学生可进入同一课堂并实时接收课堂状态；
- 老师端逐人显示在线、重连、未进入、当前环节和完成状态；
- 老师结束课堂后，学生不能继续提交已关闭环节；
- 课堂记录刷新和重新登录后仍存在；
- 私密、班级共同和给老师的内容不会串流；
- 未授权角色无法查看学生私密表达；
- 所有敏感访问和老师处理动作有审计记录；
- 系统不生成心理疾病标签、自动风险分或学生排行榜。

---

## 11. 待确认事项

1. 正式使用时的学校组织层级与账号创建方式；
2. 学生使用个人设备、校内平板还是电脑教室；
3. 私密内容的默认可见角色和授权方式；
4. 学校人工关注流程的负责人、响应时限与升级机制；
5. 小悦悦接入的模型、知识边界、内容安全和人工兜底；
6. 数据部署区域、保留期限及学校导出/删除要求；
7. 首批试点年级、班级数量与课堂验证指标。
